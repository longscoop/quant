# 研究决策工作台设计

## 目标与边界

将现有“数据表格页”升级为可理解、可验证、可追溯的研究工作流。产品输出仅为研究信号和历史验证结果，不提供个股买卖指令、收益承诺或个人化投资建议。

用户应能在每一页回答四个问题：数据是什么、是否可信、结果代表什么、下一步做什么。

## 共同交互与术语

新增共享展示层，供 Streamlit 各页面复用：

- 中文字段标签和简短解释；数值提供方向说明、计算口径和局限。
- 状态卡片：`已完成`、`不可训练`、`数据不足`、`待执行`、`失败`，均包含可执行的下一步。
- 数据质量提示：数据最新交易日、证券/价格/财务覆盖率、缺失字段数量。
- 风险提示：所有排名和模型分数均标记为“研究信号”，不构成买卖建议；展示历史结果不代表未来表现。
- 统一的研究流程导航：数据同步 → 因子构建 → 模型预测 → 回测验证。

## 第一期：研究可读性

### 总览

以流程看板替代纯计数卡：

1. 数据：最新交易日、覆盖证券数、数据缺失提示。
2. 因子：最近运行的状态、因子日期覆盖范围、下一步链接。
3. 模型：最近运行的状态、训练区间、预测日期及不可训练原因。
4. 回测：最近运行的状态、核心历史指标或“需要完成模型”的提示。

### 个股数据

保留名称（代码）选择框，增加：

- 研究摘要卡：最近收盘、相对沪深300区间表现、可用财务披露日、数据状态。
- 价格图同时显示证券复权收盘与沪深300归一化走势。
- 财务字段显示为中文名称，并提供“高/低通常反映什么”的说明；缺失或非有限字段需明确标记为“未披露/不可用”，不可伪装为经济含义。

### 因子研究

展示六类因子的中文定义、方向和适用限制。对选中运行显示覆盖行数、日期范围、每项因子的计算说明与缺失情况；明示“分数为同日横截面相对排名，不是目标价或交易指令”。

### 模型训练与结果

训练按钮后展示真实运行状态，不能将 `not_trainable` 显示为成功。`not_trainable` 必须说明缺少历史因子快照、预测日期不在因子日期范围、或标签不足等原因，并指向修正动作。

已完成模型展示研究候选排名：`研究候选`、`中性`、`低优先级`三个信号标签，附模型版本、训练截止日、预测日期、股票数量和有效性限制。默认预测日期取已选因子运行中最新的可用因子日期。

### 回测结果

在图表和表格前放置结论卡：相对基准收益、最大回撤、换手和成本。明确历史回测仅说明规则在给定样本内的表现，不应推导为未来收益或直接买卖决定。

## 第二期：研究验证

### 因子诊断

为每个因子计算并展示：覆盖率、缺失率、分位组未来收益、IC、Rank IC 及按日期的稳定性。因子样本不足时显示“证据不足”而非输出误导性指标。

### 模型诊断

为已完成模型保存并展示训练样本数、训练区间、样本外预测分层的未来超额收益、分层单调性和覆盖率。特征贡献仅在真实 LightGBM 路径可获得时展示；线性回退路径须明确标识。

### 回测归因与执行检查

扩展回测输出：年化收益、年化波动、夏普比率、最大回撤、胜率、换手率、成本拖累、相对沪深300收益、持仓和调仓明细。增加交易可行性检查：停牌、涨跌停、ST、新股、集中度和数据最新性。

### 研究决策清单

提供用户自检而非操作建议：

1. 数据是否覆盖目标日期且足够新鲜。
2. 因子/模型是否有足够样本与稳定性证据。
3. 回测是否包含成本并经受回撤检验。
4. 标的是否通过可交易性和集中度检查。
5. 用户是否已根据自身风险承受能力独立决策。

## 数据与实现边界

- 新计算结果作为运行 payload 的版本化字段保存，保持旧运行可读。
- 诊断仅使用该时点之后的已实现收益，且在展示中标注为历史评估，避免泄漏进同日预测。
- 缺失、NaN、无穷数据必须在质量层保留原因；因子层可中性化处理，但页面需显示数据质量风险。
- 所有新图表应在无数据、样本不足和失败运行时给出中文空状态。

## 验收标准

1. 每个主页面提供中文说明、当前状态和明确下一步。
2. 不可训练模型显示真实原因与修复路径，不被标记为成功。
3. 个股、因子、模型和回测的核心数值均可追溯到定义、日期范围和数据覆盖。
4. 第二期诊断在样本不足时拒绝给出伪精度结果。
5. 页面不提供“买入/卖出”指令或收益保证，研究信号和风险提示始终可见。

## 非目标

- 不接入券商账户、下单或自动交易。
- 不替代持牌证券投资咨询或根据个人财务状况提供建议。
- 不在本次范围引入实时行情或新的外部数据供应商。
