# 个股详情估值走势与财务单位设计

## 目标

将个股详情中的逐行估值原始值替换成可切换的估值折线图，并使财务披露明细的数值带有业务单位。

## 用户可见行为

- “专业详情”中展示“估值走势”，提供市盈率、市净率、市销率、股息率四个互斥选项。
- 图表的横轴是估值数据日期；只绘制当前选择指标的有限数值，缺失值不伪造为零。
- 每个指标有清晰单位：市盈率、市净率、市销率为“倍”，股息率为“%”。
- 删除“估值原始值”标题、估值字段状态表与逐日估值数据表。
- “财务披露原始值”更名为“财务披露明细”，其中营业收入、净利润、经营现金流显示为“亿元”；净资产收益率、毛利率、资产负债率、股息率显示为“%”；市盈率、市净率、市销率显示为“倍”。
- 底层 FinancialRecord 与 ValuationBar 的原始数值、披露日期和 PIT 匹配规则不变；单位仅在面向读者的投影层格式化。

## 空值与数据含义

- 业务字段为空时，图中忽略该点；若所选指标没有有限数据，显示“暂无可展示的{指标}走势”。
- 不将业务字段为空表述为研究证据不足。
- 财务披露行中空值继续显示“不可用”。

## 验收标准

- 页面有一个原生 Streamlit 单选分段控件，默认选择“市盈率”。
- 页面有且仅有该选择指标的一条估值折线数据序列，不再渲染估值原始表。
- 财务披露表的单位格式可由纯函数回归测试验证。
- 页面 AppTest 覆盖控件、默认图表、切换后图表，以及无数据提示。
