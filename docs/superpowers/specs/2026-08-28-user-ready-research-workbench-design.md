# 面向普通研究者的量化研究工作台设计

## 背景

当前系统已经具备沪深300数据同步、PIT 因子、模型评分、组合草案、策略回测和运行审计，但页面仍以内部实现概念组织。用户需要理解因子运行、模型运行、运行 ID、数据库状态和同步流程，才能完成一次研究。

本设计将系统改造成面向“懂股票、但不熟悉量化”的普通研究者的研究助手。首要路径是发现候选、看懂证据、加入组合并进行历史验证。真实数据由管理员提前准备，普通用户不配置数据库或 Tushare Token。

本设计在与 `2026-08-23-research-decision-workbench-design.md` 冲突时优先；原设计中关于 PIT 安全、真实状态、研究边界和不可训练处理的要求继续有效。

## 产品目标

普通用户进入应用后能够：

1. 确认研究数据的日期和可信状态。
2. 找到值得进一步研究的股票并理解入选原因与主要风险。
3. 查看个股证据，而不必先理解量化模型术语。
4. 将候选加入研究组合，调整权重并查看集中度与历史表现。
5. 区分用户手动调整与策略模拟调仓，查看个股收益和组合收益贡献。
6. 使用历史验证检验研究假设，而不是接收买卖指令。

管理员能够在独立入口完成数据和研究任务，并从明确的状态、进度和错误信息中恢复失败运行。

## 用户与权限边界

### 普通研究者

- 默认只看到研究、组合和历史验证能力。
- 不看到数据库连接串、Token、运行 ID、任务心跳或底层堆栈。
- 因子、PIT、模型版本等专业信息放入可展开的“专业详情”。
- 页面使用“研究候选”“值得关注的原因”“主要风险”“数据可信度”等语言，不输出“买入”或“卖出”。

### 管理员

- 通过部署配置启用管理员入口；默认关闭。
- 管理员工具不是身份认证系统。公开部署必须关闭管理员模式；需要同时提供公开与管理入口时，应使用两个部署实例或在未来接入正式认证。
- Token 只从密码输入或运行环境取得，不写入数据库、不写入日志、不回显。

## 信息架构

应用采用四个概念区域；普通用户只看到前三个：

| 区域 | 页面 | 目的 |
| --- | --- | --- |
| 研究 | 研究首页、候选池、个股详情、行业观察 | 发现候选并核对证据 |
| 组合 | 我的组合 | 保存候选、调整权重、查看收益与风险 |
| 验证 | 历史验证、验证结果 | 检验研究假设和组合历史表现 |
| 管理 | 数据与任务、运行审计 | 准备数据、执行研究流水线、诊断失败 |

核心用户路径为：

`研究首页 → 筛选候选 → 查看个股证据 → 加入组合 → 检查组合 → 历史验证`

## 页面设计

### 研究首页

首页回答四个问题：数据是否可靠、哪些股票值得研究、为什么入选、下一步做什么。

- 顶部状态条显示最新交易日、覆盖股票数和数据健康状态。
- 市场概览仅显示有可靠数据支持的沪深300表现、趋势和风险提示；不可用指标不占据主卡片。
- “研究候选”默认显示 5–10 只股票，包括名称、行业、综合表现、核心优势、主要风险和数据可信度。
- 评分使用自然语言解释，如“盈利质量优于多数同业”；专业分位和模型字段可展开查看。
- 每项候选提供“查看研究详情”和“加入研究组合”，并提供“查看全部候选”。
- 首次访问使用三步引导：选择候选、核对证据、加入组合并验证。
- 数据尚未准备完成时，普通用户看到简洁的准备状态和数据日期，不看到管理操作。

### 候选池

- 支持名称、代码和行业搜索。
- 默认筛选项为研究倾向、数据可信度和风险水平。
- 分数、覆盖率和模型来源放入高级筛选。
- 候选行可展开摘要，并提供查看详情与加入组合操作。
- 使用上一页、下一页和总数提示代替裸页码输入。

### 个股详情

- 顶部显示公司、代码、行业、数据日期和研究结论。
- 首屏展示值得关注的原因、主要风险和数据充分程度。
- 展示个股与沪深300的归一化收益走势。
- 按盈利、成长、估值、趋势和风险组织证据，并解释分数方向与局限。
- 财务原始数据、因子分位、披露日期和模型版本放入专业详情。
- 加入组合后显示已加入状态，可直接修改目标权重。

### 我的组合

组合页包括六个区域：

1. 当前组合：成员、当前权重、剩余权重、行业集中度和风险提示。
2. 收益表现：组合与沪深300的累计收益、年化收益、最大回撤和相对收益。
3. 个股贡献：持有期收益、组合收益贡献、持有天数和当前权重。
4. 调仓历史：统一时间线，以标签区分“我的调整”和“策略调仓”。
5. 调仓详情：调入、调出、权重变化、成本影响及当时的研究依据。
6. 历史版本：查看任一手动调整后的组合快照，不静默覆盖当前组合。

多个权重在表单中统一保存。提交前校验总权重；超过 100% 时说明超出多少。收益展示明确标注为历史模拟，不冒充真实账户收益。

### 历史验证

- 可从候选、当前组合或策略模板进入，不要求用户选择运行 ID。
- 基础参数使用持仓数量、调仓频率、交易成本和验证区间等通俗名称。
- 高级模型与因子参数默认折叠。
- 结果优先显示收益、回撤、相对沪深300表现、调仓次数和成本。
- 同页显示个股收益贡献、历史调仓和年度表现。
- 始终显示数据区间、模拟规则和历史结果局限。

### 管理员后台

管理员后台是第一实施阶段，包含：

- 总览：数据最新日期、沪深300覆盖、行情/财务/估值完整性、各流水线最近状态。
- 任务向导：数据同步 → 完整性检查 → 因子构建 → 模型生成。每一步只在前置条件满足时开放主要操作。
- 任务进度：阶段、完成数量、总量、最后心跳、开始时间和可理解的当前说明。
- 结果摘要：输入区间、产出数量、缺失证券数量、状态和下一步。
- 失败恢复：失败原因、建议动作和安全重试。运行中或已有等价任务时禁止重复启动。
- 运行审计：按任务类型、状态和日期筛选；运行 ID 仅在管理员详情中显示。
- 凭据保护：Token 使用密码控件，不持久化、不显示；数据库连接串仅来自部署环境。

## 数据与状态设计

### 管理任务

现有运行记录继续作为同步、因子、模型和回测的事实来源。管理员展示层使用统一任务状态视图，将底层状态转换为：待执行、进行中、已完成、需要处理和失败。

每个状态必须提供：

- 是否允许下一阶段执行。
- 用户可理解的摘要。
- 管理员可执行的下一步。
- 可选的技术详情和运行 ID。

安全重试复用原有任务参数并创建新的审计运行，不覆盖失败记录。启动前检查同类型运行中的任务及等价参数，避免并发重复执行。

### 组合版本与调整事件

第三阶段新增以下持久化概念：

- `portfolio_versions`：组合版本、创建时间、来源和备注。
- `portfolio_version_positions`：版本内每只股票的目标权重。
- `portfolio_adjustment_events`：用户手动调整事件及前后版本。
- 策略调仓继续保存在回测运行结果中，不写入用户调整表。

组合页面在展示层合并两类时间线，但每条记录保留来源，不允许将模拟策略调仓误标为用户行为。

个股收益按共同可用交易日计算；组合贡献基于期初权重和个股区间收益，并单独展示交易成本影响。数据不足时拒绝输出伪精确结果。

## 反馈、错误与空状态

- 每个空状态只提供一个最合适的下一步。
- 耗时操作显示阶段和进度，并持续刷新最后心跳。
- 日期、权重和前置数据在任务启动前校验。
- 成功反馈说明产生了什么结果及可前往的下一页面。
- 普通用户只看到可恢复的业务提示；系统错误返回参考编号。
- 管理员可查看已清理敏感信息的技术原因。
- 数据过期时允许查看已有结果，但所有相关页面持续显示数据日期和过期状态。

## 实施顺序

### 第一阶段：管理员后台

重组数据状态、同步、因子和模型操作，提供统一任务向导、进度、前置条件、安全重试和审计筛选。普通用户入口暂时保持现有功能，但管理员模式默认关闭。

### 第二阶段：普通用户研究体验

重构研究首页、候选池和个股详情，替换内部术语，打通候选、详情和组合操作。

### 第三阶段：组合与历史验证

新增组合版本与调整事件、个股收益贡献、两类调仓时间线、历史版本和验证结果整合。

## 测试与验证

### 自动化测试

- 管理模式关闭时不生成管理员导航或操作控件。
- 管理任务前置条件、状态映射、参数校验和重复运行保护。
- 失败任务重试创建新审计记录且不修改旧记录。
- Token、数据库连接串和底层异常不会进入普通用户输出或持久化 payload。
- 组合版本不可变、调整事件前后版本正确、两类调仓来源不混淆。
- 个股收益、组合贡献、成本影响和数据不足路径。
- 现有 PIT、因子、模型、回测和研究边界测试继续通过。

### 运行与视觉验证

- 使用项目虚拟环境运行完整测试套件。
- 启动 Streamlit，分别检查管理员模式开/关时的导航和页面。
- 验证桌面宽屏和窄屏下的布局、表单、表格与反馈。
- 使用成功、数据为空、任务运行中、不可训练、失败和数据过期六类状态走查管理员流程。
- 确认普通用户无法从可见导航访问管理操作，且页面不存在凭据泄漏。

## 验收标准

1. 管理员可以在一个连续页面完成数据到模型的流水线，并理解每一步的状态与下一步。
2. 管理任务失败后提供可执行的恢复方式；安全重试不会覆盖旧审计或启动重复运行。
3. 管理员模式默认关闭，普通用户导航和页面不显示管理操作及敏感技术信息。
4. 普通用户首页优先展示研究候选、入选原因、主要风险和数据可信度。
5. 候选池、个股详情和组合形成连续操作路径。
6. 组合同时提供用户手动调整与策略模拟调仓，来源清晰且可追溯。
7. 组合显示个股收益、收益贡献、调仓成本和基准对比；数据不足时明确拒绝计算。
8. 所有历史结果均标明模拟规则、数据区间和非投资建议边界。
9. 所有自动化测试通过，并完成 Streamlit 管理模式开关与关键状态的运行走查。

## 非目标

- 不接入券商账户、真实持仓、下单或自动交易。
- 不提供个性化投资建议、买卖指令或收益承诺。
- 本轮不建设登录、账号、权限、多租户或付费系统。
- 不引入新的外部行情供应商或实时行情。
- 不将管理员配置开关宣称为身份认证或安全边界。
